# Tejas Planner

This project is a desktop-first student planner dashboard inspired by the provided app ideas and Figma-style prototypes.

## Included views
- Dashboard / home overview
- Daily schedule with time blocks
- Homework & exam tracker
- Subject detail panel
- Pomodoro / focus control

## Run locally
Open `index.html` in a browser, or serve the folder with a simple static server:

```bash
python3 -m http.server 8000
```

Then visit: http://localhost:8000

## Files
- `index.html` – app structure and content
- `styles.css` – layout and visual design
- `script.js` – simple UI interactions
